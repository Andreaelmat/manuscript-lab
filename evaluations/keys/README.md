# Answer keys

These files grade a finished review. They are not review input.

Do not open this directory while producing a review. A review that reads a key is contaminated, even when the agent did not write the key.

A review is also contaminated when the same agent wrote the manuscript or the key and then reviewed the manuscript. Record that limit. Do not present the result as independent evidence that the skill works.

The first benchmark's key remains at `examples/benchmark/known-issues.md` for the existing fixture. Leave that file where it is. The long-distance key is only here, so it does not sit beside the manuscript an agent is asked to read. The decision-audit key is `the-glass-orchard-known-issues.md`, also only here. Do not import findings from another novel into that key.
